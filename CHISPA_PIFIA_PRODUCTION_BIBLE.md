# Chispa-Pifia / absurd stickman Shorts production bible

## Goal
Produce original 20–45 second absurd-comedy Shorts with an immediate hook, causal escalation, and a surprising payoff. This is a production specification, not a promise of virality.

## Visual identity
- Expressive 2D stickman cartoon, bold clean black outlines, round simple head, minimal facial marks, thin limbs, readable hands and exaggerated poses.
- Keep the protagonist unmistakably a stickman. Use the same head, face style, limb thickness, clothing silhouette, palette and line weight in every beat.
- Use simple but legible environments; prioritize action readability over decorative detail.
- Vertical 9:16 framing, clear silhouette, one obvious focal action, foreground/background separation.
- No photorealism, 3D/Pixar look, anime, live action, stock-photo appearance, style switching, accidental duplicate protagonists, logos, captions, speech bubbles, watermarks, or deliberate readable text.
- Image generation is not full animation. Never describe pan/zoom over a still as character animation.

## Story architecture
1. Start with the problem and a strange visual in the first 1–2 seconds.
2. Establish a relatable goal.
3. Make the protagonist choose a bad but understandable solution.
4. Show a direct consequence.
5. Escalate from that consequence; avoid disconnected random gags.
6. Plant or preserve a detail that makes the twist feel earned.
7. End immediately after the punchline; no moral or generic outro.

## Beat design
- Target 18–28 distinct visual beats for a 20–45 second Short, with 16–32 accepted by validation.
- Split on meaningful changes in action, reaction, consequence, object state, location, reveal, or punchline—not automatically on every comma.
- Most beats should last about 0.7–1.8 seconds; allow longer holds only for a deliberate reaction or reveal.
- Vary wide, medium, close-up, and reaction framing when it improves clarity.
- Every image must reenact the narration's exact beat. No unrelated visual gags.
- The opening image must communicate the premise without requiring captions.

## Editing and sound
- Narration is the master timeline. Cuts should align to action and spoken phrases.
- Use restrained, purposeful sound effects for impacts, transitions, surprises, movement, and phone/door/object actions when available.
- Keep voiceover intelligible above music and effects. Use brief silence when it strengthens a comedic pause.
- Camera motion can add energy to still images, but it is not a substitute for actual character motion.

## Quality gate before upload
- Confirm 9:16 aspect ratio, valid MP4, usable audio, non-empty narration, and no accidental black/silent segments.
- Confirm no deliberate text was generated in images; reject images whose text becomes plot-bearing or distracting.
- Review a contact sheet for character consistency, scene order, repeated frames, and obvious style drift.
- Confirm the first 2 seconds establish a clear hook and the ending pays it off.
- Do not infer video quality or distribution from view count alone.

## Provider honesty
Google Flow is not assumed to be connected. Use it only when an actual supported integration and credentials are configured and a real video output is returned. Otherwise label the pipeline as image-based, and do not claim character animation.
